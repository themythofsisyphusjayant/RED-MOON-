## Reddit — r/ProgrammingLanguages

**Title:** Qasida 2.3.0 — a safe, simple, fast language (Go's niche, Rust's lessons), self-hosting, ties/beats C in safe mode

**Body:**

Hi, I'm Jayant. I've been building a programming language called Qasida
from scratch, and 2.3.0 is live on PyPI and GitHub.

The pitch: Go's niche (safe, simple, fast tools/CLIs/servers) with
Rust's lessons — no null, immutable by default, checked arithmetic and
bounds, move semantics, pinning, fallible allocation with try_alloc,
pool allocators. Generics, traits, enums + match, spawn, defer.
It compiles to native C and runs as fast binaries, with RISC-V and
WASM backends too.

What's new in 2.3.0: the compiler is self-hosting — it compiles itself,
and has been the default since 11 Nov. The Top-500 stdlib catalogue is
at HAVE 393/500 (78.6%). Safe mode now ties or beats C on every quant
benchmark we run (matrix multiply 0.44x the runtime of C, Monte Carlo
0.75x, Black-Scholes 0.92x — chart in the repo). A 30-package public
registry is live on GitHub Pages.

- GitHub: https://github.com/themythofsisyphusjayant/RED-MOON-
- PyPI: https://pypi.org/project/qasida/ (`pip install qasida`)

Happy to answer questions — especially hard ones about the design
tradeoffs. The 500-feature roadmap is public in the repo.
